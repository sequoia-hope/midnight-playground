Font gallery

The JS game names system fonts that differ per device; the Rust port bundles open-licence substitutes under those names (SPEC 5.3). Each card draws the game's own sign strings, in the game's font strings, with one candidate standing in for the named family, rendered by mp_canvas as the port will draw them. The bundled default is first in each row. Pick one per family; assets/fonts/fonts.json holds the choice.

Regenerate with node tools/parity/fonts-gallery.mjs.
